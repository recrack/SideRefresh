# Outreach matrix

The objective is qualified use and honest feedback, never coordinated voting.
Fill in exact communities only after reading their current rules.

| Channel | Audience | Permission gate | Message asset | Timing |
| --- | --- | --- | --- | --- |
| GitHub README/Release | Existing visitors | Public release verified | Release notes + listing link | Launch |
| GitHub Discussion | Users and contributors | Discussions enabled | `announcements.md` | Launch |
| Maker's X | Existing followers | Normal account use | X post | Launch |
| Maker's LinkedIn | Professional network | Maker disclosure | LinkedIn post | Launch |
| Opt-in beta email | People who asked for updates | Explicit opt-in | Email | First hour |
| Personal site | Existing audience | Owner-controlled | Banner | Launch |
| Agent-tool community | Claude/Codex/Cursor users | Self-promotion allowed | Adapted community post | After support is stable |
| iOS developer community | Personal Team users | Self-promotion allowed | Technical scope + limitation | After support is stable |
| Open-source newsletter | Maintainers and makers | Editorial submissions open | Press blurb + demo | T−7 to launch |
| Podcast or blog | Agent tooling / iOS audience | Relevant editorial fit | Personal origin + demo | T−14 onward |

## Per-channel research fields

- Channel and direct rules URL: __________
- Maker's existing relationship: __________
- Why this audience can actually use SideRefresh: __________
- Permitted link and self-promotion format: __________
- Exact adapted opening: __________
- Owner and send time: __________
- Stop or removal condition: __________

## Disallowed

- vote exchanges, purchased promotion, bots, mass DMs, unsolicited bulk email;
- “please upvote,” even when softened as support or ranking language;
- URL shorteners, redirectors, or tracking parameters in the Product Hunt URL;
- identical drive-by posts across communities;
- posting where current rules prohibit self-promotion;
- generated or automated Product Hunt comments and replies.
