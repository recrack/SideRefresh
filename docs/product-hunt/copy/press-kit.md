# SideRefresh press kit

Updated: 2026-08-02 · English public copy

## One line

SideRefresh is an open-source Mac app that keeps one agent-built personal iOS
app running by refreshing it through Xcode before Personal Team signing
expires.

## Short blurb

SideRefresh helps people keep personal iOS apps made with Claude Code, Codex,
Cursor, or Xcode available on their own iPhone. The open-source Mac app rebuilds,
signs, validates, and reinstalls one user-owned project through Apple's normal
Xcode Personal Team flow before development signing expires.

## Boilerplate

SideRefresh is an independent, Apache-2.0-licensed macOS utility for people who build
personal iOS apps with coding agents or Xcode. It presents one app, one paired
iPhone, the latest verified installation, and the next required action in a
native English or Korean workspace. Source stays on the user's Mac; Apple
Account sign-in, certificates, pairing, trust, and Developer Mode remain in
Apple-controlled tools. SideRefresh does not install third-party IPAs, bypass
Apple signing, make Personal Team profiles permanent, or work without Xcode.

## Verified facts

- Platform: macOS 13 or later; Xcode is required.
- License: Apache-2.0.
- Scope: one owned app and one paired iPhone per configuration.
- Membership: a paid Apple Developer Program membership is not required for
  personal-device use; an Apple Account Personal Team is still required.
- Processing: local source build through Xcode and CoreDevice tooling.
- Languages: English and Korean.
- Distribution: public launch requires a Developer ID-signed and notarized Mac
  release; source builds alone do not satisfy the launch gate.
