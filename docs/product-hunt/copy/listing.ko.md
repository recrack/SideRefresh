# Product Hunt 등록 문구 한국어 참고본

Product Hunt에는 [영문 원본](listing.md)만 입력합니다. 이 문서는 소유자의
사실 검토와 한국어 홍보를 위한 참고본입니다.

**제품명**

> SideRefresh

**태그라인**

> 에이전트가 만든 iOS 앱을 iPhone에서 계속 사용하세요

**설명**

> SideRefresh는 무료 Personal Team 서명이 만료되기 전에 에이전트가 만든 iOS 앱을 다시 빌드·서명·설치하는 오픈소스 Mac 앱입니다. 개인 사용에는 유료 Apple Developer Program 가입이 필요하지 않지만 Mac, Xcode, Apple Account는 필요합니다.

**가격**

> 무료

## 제품 경계

- 사용자가 소유한 Xcode 프로젝트의 앱 1개와 페어링된 iPhone 1개를
  대상으로 합니다.
- Apple의 만료를 제거하거나 서명을 우회하지 않습니다.
- 타인의 IPA 설치, 팀·여러 기기 관리, Xcode 없는 사용은 지원하지
  않습니다.
- 최초 Xcode 로그인, Personal Team 선택, 기기 페어링, 신뢰 및 Developer
  Mode 설정이 필요합니다.
- Tailscale 경로는 선택적·실험적이며 원격 설치를 보장하지 않습니다.

**상태**는 공개 서명·공증 다운로드가 검증된 다음에만 `Available now`로
선택합니다. Maker 실명, 얼굴 사진, Product Hunt 사용자명, Release URL은
소유자가 직접 입력하고 확인해야 합니다.
