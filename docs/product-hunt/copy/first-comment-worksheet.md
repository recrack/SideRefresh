# Maker first-comment worksheet

Product Hunt prohibits AI-generated comments. This file is not a comment draft
and must never be pasted into Product Hunt. The maker completes it privately,
then writes the comment from scratch in their own voice.

## 1. Personal origin

- The actual personal app that first exposed the problem: __________
- Which coding agent or workflow helped make it: __________
- What happened when development signing expired: __________
- Why the existing manual step was painful enough to build a tool: __________

## 2. What was personally verified

- Public SideRefresh version and release URL: __________
- Mac and Xcode versions used in the final verification: __________
- First USB/Xcode installation date: __________
- Subsequent SideRefresh renewal date and evidence: __________
- Independent beta setup count, if verified: __________

## 3. Explain the exact boundary

In the maker's own words, explain:

- one project the user owns and one paired iPhone;
- normal Xcode Personal Team build, signing, validation, and installation;
- Mac, Xcode, Apple Account, pairing, trust, and Developer Mode requirements;
- local source and no Apple Account password collection;
- no third-party IPA store, signing bypass, permanent profile, or fleet support;
- optional Tailscale discovery is experimental, not a remote-install promise.

## 4. Deliberate first-release choice

- Why one app × one iPhone was chosen: __________
- What complexity was intentionally excluded: __________
- What evidence would justify expanding the scope: __________

## 5. Ask one real question

Choose one and rewrite it naturally:

- Where did first setup stop being clear?
- Which agent-built iOS workflow are you using?
- Which failure message failed to suggest a useful next action?

## Human-only review

- [ ] Written personally, without pasting generated prose.
- [ ] Sounds like the maker speaking, not a launch template.
- [ ] Every claim matches the public release and linked evidence.
- [ ] Names one limitation before asking for feedback.
- [ ] Contains no upvote request, incentive, or ranking language.
- [ ] Read aloud and edited by the maker before posting.
