# SideRefresh 한국어 프레스 자료

## 한 줄 소개

SideRefresh는 에이전트가 만든 개인용 iOS 앱을 Personal Team 서명 만료 전에
Xcode 흐름으로 갱신해 계속 사용할 수 있게 돕는 오픈소스 Mac 앱입니다.

## 짧은 소개

Claude Code, Codex, Cursor 또는 Xcode로 만든 개인용 iOS 앱은 무료 Personal
Team 개발 서명이 만료되면 다시 빌드·설치해야 합니다. SideRefresh는 사용자가
소유한 프로젝트 1개와 페어링된 iPhone 1개를 대상으로, Mac에서 Xcode의
일반 빌드·서명·검증·설치 과정을 반복하도록 돕습니다.

## 제품 소개

SideRefresh는 개인용 iOS 앱을 만드는 사용자를 위한 Apache 2.0 라이선스 macOS
도구입니다. 네이티브 한국어·영어 화면에서 현재 앱, 선택된 iPhone, 마지막
검증 결과와 다음 행동을 한눈에 보여줍니다. 소스는 사용자의 Mac에 남고,
Apple Account 로그인, 인증서, 기기 페어링, 신뢰와 Developer Mode는 Apple
도구에서 처리됩니다. 타인의 IPA 설치, Apple 서명 우회, 영구 프로필,
여러 앱·여러 기기 관리, Xcode 없는 사용은 지원하지 않습니다.

## 사실 요약

- macOS 13 이상과 Xcode가 필요합니다.
- 사용자가 소유한 앱 1개와 페어링된 iPhone 1개가 첫 범위입니다.
- 개인 기기 사용에는 유료 개발자 멤버십이 필요하지 않지만 Apple Account
  Personal Team은 필요합니다.
- 소스는 로컬에서 처리하며 Apple Account 비밀번호를 수집하지 않습니다.
- 공개 출시는 Developer ID 서명·Apple 공증 안정판 검증 후 진행합니다.

문의: `[소유자 이름과 이메일 입력 필요]`
