오픈소스 · Mac + Xcode · 앱 하나 + iPhone 한 대

코딩 에이전트가 만든 iOS 앱을 내 iPhone에서 계속 사용하세요.

SideRefresh는 사용자가 소유한 Xcode 프로젝트의 앱 하나를 다시 빌드하고 서명해 무료 Personal Team 서명이 만료되기 전에 재설치합니다. 소스 코드는 Mac 밖으로 나가지 않습니다.

소스 보기릴리스 상태 보기

Developer ID 서명·공증과 릴리스 검증이 끝난 뒤 서명된 Mac 빌드를 제공합니다.

Personal Team 서명 기간

명령 성공 여부가 아니라 확인된 설치와 서명 만료 증거를 기준으로 다음 갱신을 정합니다.

  1. 마지막 확인앱 설치 완료설치된 앱에서 서명 만료 시점을 읽음
  2. 다음 갱신만료 전 실행Mac이 깨어 있고 iPhone에 연결할 수 있을 때 실행
  3. 서명 만료갱신 기한앱을 다시 빌드하고 서명해 설치해야 하는 시점

작동 방식

서명이 만료되기 전에 정상 Xcode 설치 과정을 다시 실행합니다.

  1. 내 프로젝트 선택

    사용자가 소유한 Xcode 프로젝트 또는 워크스페이스 하나와 페어링된 iPhone을 선택합니다.

  2. 빌드·서명·설치

    SideRefresh가 설치된 Xcode와 무료 Personal Team을 사용합니다. Apple Account 암호를 수집하지 않습니다.

  3. 확인 후 예약

    설치된 앱의 서명 만료 시점을 기록하고 다음 안전한 갱신 시간을 정합니다.

필요한 것

실제 Apple 개발 환경이 필요합니다.

  • 지원되는 Xcode가 설치된 Mac
  • Apple Account와 무료 Personal Team
  • 사용자가 소유한 네이티브 iOS 프로젝트
  • 개발자 모드가 켜진 페어링·연결 가능한 iPhone
  • 예약 갱신 시 깨어 있는 Mac

Mac 안에서 처리

프로젝트는 내 Mac에 남습니다.

  • Apple Account 암호를 수집하지 않음
  • 소스 코드를 업로드하지 않음
  • 타사 IPA 스토어를 사용하지 않음
  • Apple의 정상 Xcode 서명·기기 도구 사용
  • 검토할 수 있는 Apache-2.0 라이선스 소스

첫 릴리스 범위

일부러 좁게 시작합니다.

SideRefresh는 개인 앱 하나와 iPhone 한 대에서 시작합니다. 타인의 IPA 설치, 팀·여러 기기 관리, Xcode 없는 사용, 순수 셀룰러 갱신을 첫 릴리스 기능으로 주장하지 않습니다.

  • 선택한 앱 하나와 iPhone 한 대
  • USB 또는 Xcode가 이미 사용할 수 있는 네트워크 경로
  • 실험적 연결은 실험 기능으로 명확히 표시
