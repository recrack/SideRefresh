# SideRefresh Code of Conduct

SideRefresh is committed to a welcoming, respectful, and harassment-free
community for everyone.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss ideas and code without attacking people.
- Respect differing experience levels, identities, and viewpoints.
- Accept feedback gracefully and help keep discussions focused.
- Protect private information found in logs, screenshots, or reports.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks;
- sexualized language or unwanted attention;
- deliberate intimidation, disruption, or trolling;
- publishing another person's private information; or
- conduct that would reasonably make participation unsafe.

## Reporting and enforcement

For an ordinary moderation request, open an issue containing only the minimum
non-sensitive context and ask for maintainer review. Do not repost abusive or
private material. For a report that cannot safely be public, use GitHub private
vulnerability reporting and begin the title with `Conduct:`.

Maintainers may edit or remove contributions, comments, issues, or other
participation that violates this policy. Responses may include a warning,
temporary restriction, or permanent removal from project spaces. Maintainers
will handle reports as privately and promptly as practical.

## Scope

This policy applies in all SideRefresh project spaces and when someone is
officially representing the project in public.
